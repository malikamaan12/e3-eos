## 3. Mock Fallback & Data Leak Audit Summary

1. **Eliminated Synthetic Fallbacks:**
   - Financial positions no longer default to `|| (isDemo ? 2450000 : 0)`. Unknown projects return HTTP 404.
   - Client billing summary cards compute dynamically from actual invoices and milestone collections.
   - Closeout checklists initialize to honest `false` states and derive from real activity records.
2. **Strict Project Scoping:**
   - Offline field mutations are stamped with the active `projectId` at creation time.
   - Route path resolution strips query strings and hash anchors before matching (`split('?')[0].split('#')[0]`).
   - Client results projections strictly filter out buy rates, contractor markups, and internal cost pools.
